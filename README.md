# متره فونداسیون ساپورت‌ها

اپلیکیشن اندرویدی آفلاین برای استخراج، کنترل و محاسبه احجام فونداسیون ساپورت‌های خط لوله پروپان.

## وضعیت فعلی
- اسکلت اولیه Flutter و رابط فارسی/راست‌به‌چپ
- فهرست 176 شناسه مورد انتظار
- جستجوی شناسه ساپورت
- ثبت مبانی متره مصوب
- داده‌های ابعادی هنوز در انتظار استخراج و کنترل تصویری هستند
- CI برای تحلیل، تست و ساخت APK در GitHub Actions

## مرجع فنی
مدرک 3984-60-DE-ST-DWG-005، ویرایش 01، شامل 11 شیت.
فایل PDF مرجع عمداً در این مخزن عمومی قرار داده نمی‌شود.

## مبانی متره
- فضای کار حفاری: 600 میلی‌متر از هر طرف
- ضخامت بتن مگر: 100 میلی‌متر
- دیواره حفاری: قائم
- پوشش قیری دو لایه تا 200 میلی‌متر بالاتر از GL طبق نقشه

جزئیات کامل در docs/takeoff-basis.md ثبت شده است.

## اجرای محلی
نیازمند Flutter stable و Android SDK:

\`\`\`bash
flutter pub get
dart format .
flutter analyze
flutter test
flutter run
\`\`\`

## ساخت APK
\`\`\`bash
flutter build apk --release
\`\`\`

فایل خروجی محلی:
build/app/outputs/flutter-apk/app-release.apk

همچنین GitHub Actions پس از push یا اجرای دستی workflow، APK را به‌عنوان artifact منتشر می‌کند؛ تا قبل از موفقیت اجرای workflow، APK تأییدشده محسوب نمی‌شود.

## کیفیت داده
هیچ مقدار OCR یا حدس مهندسی به‌عنوان مقدار قطعی استفاده نمی‌شود. ابعاد و آرماتورها باید با تصویر شیت کنترل شوند و موارد نامطمئن آشکارا علامت‌گذاری می‌شوند.
